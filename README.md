# Little Machines

A browser game for young children: drive a tractor through a haymaking workflow, or choose a construction vehicle and complete simple work-site missions.

The game UI is in Norwegian and supports keyboard, touch, and compatible steering-wheel/gamepad controls. A dormant peer-to-peer multiplayer client for up to four players is included, but requires a self-hosted signaling backend before it can be enabled.

## Features

- 3D tractor, excavator, dumper, and wheel-loader play
- Tractor missions: mow, rake, and bale grass
- Construction missions: dig, load, and deliver
- Sound effects and Norwegian voice prompts
- Keyboard, touch, and gamepad controls
- Dormant WebRTC multiplayer client

## Requirements

- Node.js 22.13 or newer
- pnpm (recommended; the lockfile is `pnpm-lock.yaml`)

## Run locally

```bash
pnpm install
pnpm dev
```

Open the local URL printed by the development server.

## Kjøreparken

Run `pnpm dev` and open `/racing.html` on the URL printed by Vite. The car starts in toddler mode with automatic acceleration. Turn the wheel or use ←/→ or A/D. Use ↓ or S to brake and R to reset. The cross streets meet a wide banked loop. Drive through the purple tunnel, cross the turquoise bridge or pass beneath it, try the ramps, or head off-road to kick footballs and knock down block towers. Turquoise pads give a brief boost within the configured speed limit. Follow the blue arrow signs on the east side to enter the hilltop loop at any of three junctions. The kite marks the high point, and the dirt jump sits beside the loop so you can drive straight past it. Kick a ball through the pink-trimmed goal south of the main intersection for a chime and confetti. After a goal, the ball returns when its starting spot is clear.

Head west past the purple tunnel for the stunt area. The summit arch marks the wide downhill road. A banked bend brings it back toward the park, and the open halfpipe, rolling hills, and jumps all have drive-arounds. Knock over the pins on the bowling lane or drive through a floating star for a sound and sparkles. The toys reset when you move away so you can play again.

The gear button pauses the game and opens parent settings. Choose **Sakte** for a low-speed preset, or drag the speed limit down to about 7 km/h. If a wheel disconnects during play, the car slows to a stop. Reconnect with the wheel centered and pedals released, or steer with the keyboard to continue. The **Normal** preset uses the accelerator and brake pedals or ↑/↓ and W/S. The speed limit and each driving assist can be adjusted independently. Choose Rally, Strand, or Rakett in the same panel. The cars share the same handling. The game remembers your selection and sound setting. If sound is muted by the browser, click the game or press a keyboard key once to start it. If the browser has not registered the wheel, move it or press a wheel button with the game tab focused. Center the wheel or calibrate separate/reversed pedal axes from the same panel if needed.

Use the world button to choose **Kjøreparken**, **Fjellheimen**, **Ørkenkløfta**, **Bygda**, or **Sommerlia**. Procedural worlds can be replayed with a seed, shared by URL, and saved as local favorites. To build a playground from JSON, see the [world-building guide](app/racing/worlds/README.md).

For local multiplayer, open `/racing.html` in two tabs using the same browser profile, URL origin, and world link. Another car has a turquoise diamond above it. Hidden tabs pause their own car. For simultaneous driving, put two browser windows side by side, open `/racing.html?input=keyboard` in the keyboard player's window, and keep that window focused. Interact with the wheel window once so the browser can discover the wheel. Car movement and appearance are shared between windows. Each window has its own toys, stars, and collisions.

For the physical-wheel playtest, try steering from a standstill, holding a banked turn, and releasing the wheel to center. Spend a few minutes exploring the roads and grass in toddler mode. Check the view through the tunnel and across a jump, then try braking and recovery at different speeds.

## Deploy to GitHub Pages

This repository is configured to deploy itself to GitHub Pages when changes are pushed to `main`.

1. Push this project to its own GitHub repository.
2. In **Settings → Pages**, set **Source** to **GitHub Actions**.
3. Add your intended subdomain (for example, `machines.example.com`) as the custom domain.
4. In your DNS provider, create a `CNAME` record for `machines` pointing to `<your-github-username>.github.io`.
5. Wait for DNS propagation, then enable **Enforce HTTPS** in GitHub Pages.

The site uses absolute asset paths because it is intended for a custom subdomain. The multiplayer UI is disabled so the deployed game needs no backend.
